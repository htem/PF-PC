# PF-PC

This repository provides code and resources for [Holtrup, Khajeh, Lee: Random innervation of cerebellar Purkinje cells as a substrate for diverse representational learning, biorxiv, 2026](https://www.biorxiv.org/content/10.64898/2026.06.26.734775v1).

The scripts in this repository are compatible with Python 3.11.1.
